# Network Attack Forecasting - Project Plan

## Main Goal

Forecast how many network attacks may happen in the next 5-minute time interval.

## Dataset

CIC-IDS2017 labelled network-flow dataset.

## Project Flow

Raw dataset
→ Clean data
→ Group attacks into 5-minute intervals
→ Create attack-count time series
→ Train forecasting model
→ Predict future attack count
→ Show results in a dashboard
